感谢你试用 Advisor。

■ 安装
解压后，在 Finder 里把「Advisor」拖进「应用程序」文件夹
（或者直接拖到 Dock 上）。

■ 首次启动前的一次性操作
macOS 默认会阻止来源不明的应用第一次正常打开。所以只有这次启动，
请不要直接双击，而是：

  1. 在 Advisor 上右键（或按住 Control 点击）
  2. 在弹出的菜单里选择「打开」
  3. 会出现「无法验证开发者」的提示 —— 再点一次「打开」

之后每次都可以正常双击打开。

■ 开始使用
第一次启动时会显示 API 密钥（你自己的使用许可代码）登记页面。
按屏幕提示操作即可 —— Gemini 的免费额度可以零成本先用起来。

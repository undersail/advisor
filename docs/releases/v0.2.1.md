# Advisor v0.2.1

> **之后的变更（本文件保留发布时的原文）**：中继队列后端已从 KV 换成 **Durable Object**，
> 因此不再需要 `kv namespace create`、也不需要在任何配置里填 id；`wrangler.local.toml`
> 已随之删除。当前部署方式见 `remote/relay/README.md`。

## 一句话

远程接入从零到能用（只读网关 + 出站通知 + 轮询中继传输层），发布走 tag 自动化，
并做了一次全面审计：把版本号收口成单一来源、把「密钥/个人信息/本机路径/云账号」
四类泄漏风险做成机器卡口。

## 新增能力

### 1. 远程只读网关（`remote/gateway.pl`）

从企业微信 / 飞书派活，机器留在家里那台老 Mac 上执行。

- **发送者白名单**：白名单外的消息直接丢弃并记审计，不回「无权限」——不暴露机器人存在
- **工具硬关只读**：远程模式下只给 `read_file` / `list_dir`，写文件与跑 shell 在代码里写死禁用，
  不是配置项，改不了
- **审计日志**：`~/.claude-agent/audit.log`，0600，只追加
- **独立历史**：远程对话用独立口令 + 独立历史目录，不与本地共用
- 180 秒读超时熔断；子进程管道走 UTF-8，避免双重编码乱码

### 2. 出站通知（`remote/notify.pl`）

单向推送，最省事的一档。企业微信群机器人（markdown）与飞书自定义机器人（text）都支持。

- webhook 本身就是凭据 → 用 `curl -K -` 从 stdin 喂，URL 不进 `ps` 进程列表
- 强制 https，非 https 直接拒绝；零 CPAN 依赖
- 可单独用：`perl remote/notify.pl "构建完成"` / `perl remote/notify.pl --test`

### 3. 轮询中继（`remote/relay/`，档② 第一批）

NAT 后 / 没有公网 IP 也能双向传话，代价是秒级延迟。

- Cloudflare Worker + KV 队列：`/health` `/push` `/pull` `/result` `/outbox`，全部 Bearer 鉴权
- 网关侧 `--poll` 轮询端；`pull` 取走即删
- **队列与轮询端已实现并验过**；把结果推回手机的平台端收发没做（需自建应用凭据 +
  回调验签/AES，必须真凭据联调），见「已知限制」

### 4. 发布链路（`.github/workflows/release.yml`）

打 tag 即出包：macOS runner → venv + py2app → standalone zip → 校验产物结构 → SHA256 →
`gh release create`（正文取 `docs/releases/<tag>.md`）。也可手动触发，手动只构建不发布。

### 5. 版本号单一来源（`VERSION`）

审计发现版本号原来有 7 个写入点。现在只有 `VERSION` 一个来源：
`--version`、`setup.sh` 的 wrapper 与两处 Info.plist、zip 名、Release tag 全跟它走，
`scripts/check-version.py` 在 CI 里守着。

## 安全（本版重点）

- **云资源必须自备**：`wrangler.toml` 的 `kv_namespaces` 整段注释、不留任何 id；
  使用者自己的 `wrangler.local.toml` / `.dev.vars` 一律 gitignore。
  「不填就 deploy 报错，宁可不部署，也不要留一个看起来能用、属于别人的 id。」
- **仓库零账号信息**：工作区 + 全部历史 0 处 Cloudflare 账号/区域/KV id、0 处令牌、0 处 workers.dev 子域
- **`scripts/check-secrets.py`**：22 类规则（各家 API key、私钥块、真 webhook、本机绝对路径、
  邮箱、工具状态目录、CF 账号形态…），支持 `--history` 扫全历史，已进 CI
- **历史已清理**：早前 4 个提交的作者身份是本机默认值、2 个提交误带 `.wrangler` 构建产物
  （含本机路径）、`dev_plan` 写了本机绝对路径 —— 三处已重写历史清除，仓内**从未出现任何凭据**

## 已知限制

- **档② 平台端收发未做**：结果还不能自动推回手机；目前靠档① 通知代替
- **分发版未签名**：首次启动需右键「打开」，否则 Gatekeeper 会拦
- **Tier A（macOS 10.6 ~ 10.8）未开工**：需自建 OpenSSL + curl 工具链
- **真实厂商协议层差异**：本版只验到网络通路；tools schema、`max_tokens` 语义等需真 key 自测
  （`scripts/live-check.py` 只输出 PASS/FAIL，不会打印你的 key）

## 一句话

把「装完之后真的能用」这一段补齐：**双击打不开**的根因修掉了（两个都是 macOS 独占的
真 bug，Linux 上永远复现不了），中继队列换成 Durable Object 后**连 id 都不用填**，
并且给 Gitee 镜像加了反拉保护 —— 上线第一次运行就拦下了一个会被无声覆盖的提交。

## 修掉的真 bug（这一版的重点）

### 1. 双击 `Advisor.app` 启动即崩（GUI 自递归）

```python
return _pointing_cursor() if sys.platform == "darwin" else "hand2"
```

`_pointing_cursor()` 无条件调用自己 → macOS 上 `RecursionError`，双击图标立刻退出，
连窗口都不出现；Linux 永远走 `else`，本机所有测试全绿。

### 2. 双击打不开的第二个原因：兜底选了个不存在的解释器

`setup.sh` 的兜底是 `PY3=/usr/bin/python3`，而 macOS 12.3 起这个路径**只有装了
Xcode CLT 才存在**。旧版只判「变量非空」，于是造出一个必然跑不起来的 app，全程显示正常。

现在：候选逐个 `-x` 真验、GUI 另测 `import tkinter`，缺就不生成 app 并说清缺什么
（python.org 安装包自带 Tk；只装 CLT 没有 Tk）。

### 3. `.app` 启动器的弹窗会永久挂住

解释器/源码不可用时弹 `display dialog`，没有 `giving up after` 就一直等人点「好」——
在 CI、远程登录这类没人操作的机器上是**永久阻塞**（实测吃掉 45 分钟 job 预算）。
现在加了 10 秒超时，并把文字提示（解释器路径、程序路径）挪到弹窗**之前**写 stderr。

### 4. `advisor: command not found`

PATH 写入的三个坑：`grep -qF` 把**注释掉的**那行当成「已存在」→ 一个字都不写；
只写 `~/.bash_profile`（macOS 默认 zsh **不读**）却照样报「已加入 PATH」；写完不验证。
现在只认行首真正生效的 `export`、按 `$SHELL` 追加 `~/.zprofile`、最后 `bash -lc` 真解析一次。

## 新增能力

### 1. 平台端 4 项功能补齐（企微 / 飞书回调）

- **多轮对话连续**：每个发送者一个常驻网关进程（串行、CHLD 守护重开、空闲 30 分钟回收）
- **NAT 入队**：`RELAY_URL` / `RELAY_TOKEN` 让消息投进中继队列，结果从 `/outbox` 取回再推给手机
- **长回复分片**：按**字节**切（不是字符）+ 二分保证字符边界 + `（i/n）` 前缀，企微 2048 / 飞书 4096
- **处理中提示**：3 秒没结果先回一句「收到，正在处理…」，避免平台 5 秒超时

### 2. 中继队列：KV → Durable Object

取走即删需要原子、序号只增需要 CAS、跨地区可见延迟最长约 60 秒会毁掉 5 秒级目标 —— KV 都不合适。
换成 DO 之后副作用是**更省事**：不需要 `kv namespace create`，也没有任何 id 要填，
`wrangler.toml` 只剩绑定名与迁移声明。`wrangler.local.toml.example` 因此删除。

### 3. Gitee 镜像反拉保护

镜像用 `git push --all --force` + `--tags --force` 单向强推，任何人在 Gitee 侧提交都会被
**无声覆盖**。现在推之前先跑 `scripts/check-mirror-drift.sh`：会覆盖就**中止同步**并打印反拉步骤；
已 cherry-pick 的按 patch-id 判定为已收敛、不会永久卡住；镜像独有的分支（`--all` 不删除）
与不同名 tag 只提示不拦。确认可丢弃时手动触发并勾 `force`。

> 上线第一次运行就拦下了一个真实提交（维护者在 Gitee 网页上修 GUI 递归崩溃的那个），
> 同步中止而不是覆盖它 —— 这个功能从第一天就在干活。

### 4. 提交卡口（pre-commit hook）

`bash scripts/install-git-hooks.sh` 装一次（`core.hooksPath` 指向仓库内 `scripts/hooks`，
hook 本身也受 review 与 CI 检查）：提交前跑泄漏检查、换行检查、调试残留检查，
`git commit --no-verify` 留逃生门。

## 只在 macOS 上暴露的坑（都已修，且都加了防线）

| 坑 | 表现 | 为什么 Linux 上看不出来 |
|---|---|---|
| bash 3.2 把全角字符算进变量名 | `$mb（` → 变量未定义 → 名字凭空消失、只剩半个乱码字节 | bash 5 只认 ASCII 标识符 |
| `case … in x) continue ;; esac` | 语法错误，**整段脚本静默不执行**（放进 hook 等于 hook 从没跑过） | bash 5 接受这个写法 |
| 只读一半请求体就关连接 | 客户端收到 TCP RST 而不是 400 | Linux 碰巧能先读到 |
| `pipefail` + `unzip -l \| grep -q` | SIGPIPE(141) 被判成「文件缺失」，文件明明在 | 管道缓冲大小不同（16KB vs 64KB） |
| `osascript display dialog` 无超时 | 无人值守环境永久挂住 | 没有 osascript |
| 测试子进程不给 stdin | 被测脚本里的 `read` 永久阻塞 | 本地终端会 EOF |

## 行为变化（升级须知）

- **Gitee 侧有提交时同步会中止**（不再无声覆盖）。反拉：`git fetch gitee` →
  `git log --oneline main..gitee/main` → `cherry-pick` / `merge` → `git push origin main`
- **没有可用 python3（含 Tk）时不再生成 `Advisor.app`**，而是明确拒绝并说清缺什么。
  命令行版 `advisor` 不受影响
- **中继部署变了**：不需要建 KV、不需要填任何 id，`wrangler deploy` 即可
- 首次启动 `.app` 仍可能遇到 Gatekeeper（未签名）→ 右键打开

## 已知限制

- 产物**未签名**（无 Apple Developer ID），首次启动需右键打开

发布日：2026-10-26

## 一、这一版到底做了什么

一句话：**把一个只支持 Claude / Gemini 的日文工具，变成支持 7 家厂商、三种语言、能打包分发的版本。**

分四层推进，每层都能独立回滚：

| 里程碑 | 内容 |
|---|---|
| M1 | 工程骨架：CI（ubuntu + macos 双平台）、Gitee 镜像、`.editorconfig`、设计文档与开发计划 |
| M2 | 中文化：译文 242 条（Perl `%S` 96 + GUI `_S` 59 + `setup.sh msg()` 41×3 等），跟随系统语言 |
| M3 | 提供商注册表重构：4 处 `if/elsif` 分派收敛为 `%PROVIDERS` 查表，**行为零变化** |
| M4 | OpenAI 兼容适配器 + 7 家厂商 + 两级模型菜单 + GUI/`setup.sh` 全面适配 |

## 二、支持的厂商

| 厂商 | 命令 | 默认模型 | 说明 |
|---|---|---|---|
| Anthropic | `/claude` | `claude-sonnet-5` | 原生协议 |
| Google | `/gemini` | `gemini-3.5-flash-lite` | 原生协议 |
| OpenAI | `/openai` | `gpt-4o` | 兼容适配器；大陆网络需 `CLAUDE_BASE_URL` 指代理 |
| DeepSeek | `/deepseek` | `deepseek-chat` | 兼容适配器 |
| 通义千问 | `/qwen` | `qwen-plus` | 兼容适配器（DashScope） |
| Kimi | `/kimi` | `kimi-k2-0905-preview` | 兼容适配器（Moonshot） |
| 智谱 | `/glm` | `glm-4.6` | 兼容适配器（BigModel） |

后五家共用同一套请求构造与响应解析，彼此只差密钥变量名、默认模型和 base_url。

## 三、按主题的变更

### 中文化（M2）
- Perl 侧 `%S` 96 条、GUI `_S` 59 条、`setup.sh` 的 `msg()` 41 条全部补齐中文（`acdd0b7`、`c4bc0ba`、`18af25a`）
- `models.txt` 增加中文说明列；`--help` 增加中文分支（`print_help` 是单引号 heredoc，另起分支实现）
- 新增三语占位符卡口 `scripts/check-i18n.py`：某条文案只译了一半、或占位符个数不一致，CI 直接红

### 提供商抽象（M3）
- `my %PROVIDERS` 注册表取代 4 处分派；用 6 组输入对比重构前后输出，**逐字节一致**（`f2b3eb6`）

### 多厂商（M4）
- OpenAI 兼容适配器：`tool_calls` ↔ `tool_use` 转换、`tool_call_id` 回传、`reasoning_content` 解析阶段丢弃（回传会 400）
- `models.txt` 扩到 7 列（`id|ja|en|zh|provider|base_url|[flags]`），12 条模型（`d6d1541`）
- 两级模型菜单：终端用数字选厂商再选模型；GUI 用 `/model <id>`（编号会随插入错位，所以发 id）
- `providers.txt` 成为厂商数据唯一定义处 —— 密钥变量名与默认模型**只**在这里，代码里出现就红（`scripts/check-models.py`）
- GUI：首启页 7 家下拉（选中即跳该家密钥页）、主界面按厂商分级子菜单、保存一家密钥不会清掉别家（`4016d50`）
- `setup.sh`：厂商清单 / 密钥变量 / 默认模型 / 密钥页 URL 全部从 `providers.txt` 取；连通性测试按三家协议形状分支；**避开 bash 4 特性**（macOS 自带 bash 3.2）
- `--help` 的厂商与密钥表改为生成式，不再写死「anthropic 或 gemini」

### 验证工具
- `scripts/check-models.py`：`providers.txt` ↔ `models.txt` ↔ `%PROVIDERS` 三方一致性
- `scripts/ci-local.py`：本地**真跑** `ci.yml` 的每个步骤（不是手抄检查逻辑 —— 手抄两次都导致本地绿线上红）
- `scripts/live-check.py`：真机自查连通性，key 只从环境变量读、只输出 PASS/FAIL、`curl -K -` 走 stdin
- `docs/manual_test_mac.md`：Mac 真机验收清单（每步写「应看到什么」「不对时发什么」）

## 五、安装

**方式一（推荐）**：下载 `Advisor-v0.2.0-standalone.zip`，解压后双击 `Advisor.app`。
首次启动 macOS 会提示「无法验证开发者」—— 右键 → 打开，或按 zip 里 `ReadMe_ZH.txt` 的说明处理。
首次启动会出现密钥注册页，选一家厂商、粘上自己的 API key 即可。

**方式二（从源码）**：`bash setup.sh`，需要 macOS 10.9 以上（系统 curl 能说 TLS 1.2）。

- **Mac 真机**：GUI 只在 Xvfb 里做过控件树内省（21 项断言），视觉排版（下拉宽度、间距、字号）需要真人过目。
- **分发版打包**：`release/build_standalone_app.sh` 只能在 macOS 上跑；本会话仅验证到 `bash -n`。本版的 zip 由后续的 Release 流水线首次实际产出。
- **默认模型名会过期**：`claude-sonnet-5`、`gpt-4o` 等是写字的时候有效的名字，厂商改版后会失效，届时改 `models.txt` 即可（不用改代码）。

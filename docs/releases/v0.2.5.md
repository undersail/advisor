# Advisor v0.2.5

发布日期：2026-10-31
上一版：`v0.2.4`（`4b9c24e`，2026-10-30）
本版范围：`v0.2.4..v0.2.5`，19 个提交（+ 本版说明这 1 个 = 20）

## 一句话

**这一版主要是「把不顺手的都磨掉」**：记忆与会话接续补齐（不用手敲参数）、历史改成默认明文
（不再每次启动问口令）、bypass 语义改清楚、远程面板重做、GUI 六条实机缺陷修掉。过程中挖出
**三个真 bug**，都不是观感问题：安装包从未携带 `remote/`（远程面板必然失败）、加密历史的
`key.enc` 被当成明文读（**正确口令也永远打不开**）、中文会话里冒出日文旁白（工具说明是日文，
把模型带跑了）。

## 新增：长期记忆与技能目录（`2eb6fd0`）

- 记忆：`~/.claude-agent/memory.md`（明文 `0600`，≤2000 字符），写入必须确认（bypass 也问），可看可删
- 技能：`~/.claude-agent/skills/<名>/SKILL.md` 或 `<名>.md`
- **只注入「名字 + ≤80 字描述 + 路径」**，正文按需 `read_file` —— 不把技能全文塞进每一轮 prompt

## 新增：会话接续与找回（`832ac10`、`955d894`）

命令行：

| 参数 | 作用 |
|---|---|
| `--continue` / `-c` | 接着最近一场（**绝不读 STDIN、绝不弹菜单**，供 RPC / 网关无人值守） |
| `--continue <名字>` | 按名字接着某一场 |
| `--name <名字>` | 给本场起名 |
| `--search <关键词>` | 在历史里全文检索（中文不乱码） |

会话内（不用记参数，`955d894`）：`/name`、`/history`、`/search`，与命令行**共用同一份实现**；
GUI 增加「会话」菜单（接着上次 / 接着指定 / 列出 / 起名 / 搜索）。`--no-config` 会话里三条命令一律拒绝。

远程按发送者自动续接：会话键 `remote:<md5 前12位>`（原始 ID 只进审计日志，不进文件名）。

## 变更：历史默认明文，加密改为可选（`331a043`）

- 默认 `~/.claude-agent/history/<时间戳>.json`（文件 `0600`、目录 `0700`），**启动不问口令**
- 要加密：`--encrypt-history` / `CLAUDE_ENCRYPT_HISTORY=1`
- 判定「有没有加密历史」只看 `key.enc`（或旧 `.check`）；孤儿 `*.json.enc` 不改变模式
- **不做自动迁移**：把用户以为加密的内容悄悄变明文，必须由用户自己敲命令

## 修复：加密历史其实一直解不开（`abe55f0`）

`hist_plain_encrypted()` 只把 `*.json.enc` 当密文，于是包着主密钥的 `key.enc`（以及
`key.recovery.enc`、旧 `.check`）被判成**明文**，交给 `openssl` 之前就按 UTF-8 文本读了一遍 ——
**正确的口令也必然打不开**，日志里还刷 `does not map to Unicode`。现在凡 `.enc` 与 `.check`
一律当密文。

新增 `--make-plain-history`：备份 → 解密 → 写出 `*.json`(0600) → 删 `key.enc`。有文件解不开
就中止且**什么都不删**，备份留在 `~/.claude-agent/history-backup-<时间>`。CLI 解口令时先试
`CLAUDE_HIST_PASS`（自动化与远端走同一条路），试不通再转交互问。

## 变更：bypass 语义（`25f30d2`）

`bypass` = **除了危险命令和文件/目录操作，其余都不问，且不受可写范围限制**。白名单只管
`accept-edits`。永久禁止目录（`/etc`、`/usr`、`~/.ssh`、`~/.claude-agent`）任何模式直接拒，
连确认都不给。目录类操作只认命令名（跳过 `sudo`/`env`/`xargs` 与 `-选项`），
`echo rm -rf nothing` 不误判、`sudo rm x` 能识别。

## 修复：GUI 六条实机缺陷（`abe55f0`、`1078062`）

| 缺陷 | 真因 | 修法 |
|---|---|---|
| 启动服务报「找不到 wecom-ws.pl」 | `setup.sh` 与打包脚本**从未携带 `remote/`** | 两处都加；找不到时报出搜过的 4 个路径 |
| 远程面板排版乱、说法不一致、字体不同 | 结果标签每次操作都 `pack()` 一次（内容会跳到末尾）；面板用「只读/可编辑/放开」，主界面用「默认/写文件免确认/Bypass」；面板裸 `tk.Label` 不走主题书体 | 三个分组框 + 结果区固定 grid；档位直接用主界面同一套文案；统一字体与主题色 |
| 启动后打不了字 | macOS 上窗口没成为前台应用时 `focus_set/focus_force` 拿不到键盘 | 启动时 `deiconify/lift/topmost` 闪一下 + `focus_force`；5 秒内每 400ms 自查；12 次不行才放弃并**在状态栏与会话里说明**；兜底把焦点外打的可打印字符送进输入框 |
| 输入区与输出区看不出区别 | 输入框底色**故意**与会话区同色 | 输入区用自己的底色 + 上方 1px 分隔线（三套主题都补了 `input_bg`） |
| GUI 是否依赖命令行 | 不依赖（双击 `.app` 即可）；「像依赖」的根源是上面第一条 | 打包带 `remote/` 后不再成立 |
| 启动仍要口令 | 见上「加密历史其实一直解不开」 | 修根因 + `--make-plain-history` |

## 修复：中文会话里冒出日文（`76abe53`）

`read_file`/`write_file`/`list_dir`/`run_shell` 的 description 原本是日文，模型会照工具文档的
语言写旁白，而系统提示只说「reply in the same language」，盖不住进度说明。现在工具说明改中性
英文，系统提示升级为**语言锁定条款**（回复、进度说明、状态行、工具调用前后写的话都必须用用户
语言，并明说「工具说明是英文不改变输出语言」「中文会话绝不出现日文」）。

## 变更：源码去日文化（`d489eec`…`9f9780c`，9 个提交）

代码里不再写日文：注释技术/中性用英文，其余简体中文，写死的用户文案一律中文。
**保留 i18n 词条**（`%S` 的 `ja =>`、GUI 的 `"ja":`、`msg()` 的 ja 分支、日语 `--help`、
接受 `はい/いいえ` 的确认词正则）—— 那是可选日语界面本身。

```bash
git reset --hard v0.2.4
```

本地历史与新格式文件不受影响：记忆 `~/.claude-agent/memory.md`、技能目录、明文历史都是 v0.2.5
引入的，回退后旧版会忽略它们（不会删除）。

## 已知问题 / 未在本机验证的部分

- **企微真机链路**（长连接收发、白名单、手机确认 y/n、断网重连）需要你在 Mac + 手机上验，
  本机只能做到协议级与单元级验证。
- **macOS 焦点问题**：修法基于「窗口没成为前台应用」这一判定，本机（Xvfb）只能验证看护逻辑与
  兜底插入，**不能复现真机表现**——如果你点了输入框仍然打不进去，那是另一条链路，需要状态栏那行字。
- **`--make-plain-history`** 的真实加解密往返已在测试里覆盖（造加密文件 → 转换 → 校验内容与权限），
  但**没有在你机器上的旧历史目录上跑过**。
- App 签名分发仍需 Apple Developer ID，当前保持「右键打开」。Tier A（10.6~10.8）依旧暂缓。
